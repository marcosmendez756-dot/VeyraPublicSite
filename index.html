Veyra

Developer language · Early prototype

A language for building more.

Veyra is an early-stage general-purpose programming language project. Its long-term goal is to help people create software, websites, games, bots, and applications through one approachable language.

  • Building the language runtime
  • Expanding core programming features
  • Planning libraries and developer tools
